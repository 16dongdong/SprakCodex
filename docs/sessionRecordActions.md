# 会话记录操作（0.6.5）

- 会话列表不再显示三点按钮，右键会话行打开操作菜单；详情区保留直接操作入口。
- “删除会话记录”需要确认。复用 `sessionRouting/reset`，原子删除 `session_routing_bindings` 中的记录，包含绑定账号、待切换账号及标题缓存。
- 不删除 Codex 原始聊天内容，也不清空请求日志。该会话下次接入时重新分配账号并建立新记录。
- 已开始的请求继续完成；现有连接按原生命周期检查失效绑定，不重放请求。
- 删除当前页唯一记录后返回上一页，清除旧选中项并刷新绑定计数。

验证：前端 lint、运行时测试和静态导出；Playwright 隔离 RPC 样本验证右键目标、菜单、取消删除、确认删除参数及删除后的空状态，不删除真实用户会话。
