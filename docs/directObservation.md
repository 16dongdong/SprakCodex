# 直连观测

直连观测是 CodexManager 内置的本地网络观测引擎，不启动 `CProxy.exe`，也不创建第二个管理进程。

## 使用方式

1. 打开“Codex 接入方式”页面。
2. 在“直连观测”卡片点击“启用观测”。
3. 从 CodexManager 的“项目启动”重新打开 Codex 终端；已经运行的终端不会被注入或改写。
4. 使用结束后关闭观测，再退出该终端。

每次 CodexManager 后端重启都会清理临时监听和证书，需要重新启用。观测公开证书只写入本地临时文件，私钥仅存在后端进程内；不会安装系统根证书、修改 `auth.json` 或系统代理。

## 记录和费用

- `/v1/responses`、`/v1/chat/completions`、Codex Responses 路径支持非流式、SSE 和 WebSocket。
- 请求日志保存方法、路径、状态、耗时、模型、实际用量和错误原因；认证头、Cookie、提示词、工具参数、响应正文不会写入数据库。
- 有完整服务端用量和匹配价格时，直连观测会创建现有 `request_charge_snapshots` 费用快照，并更新该请求的费用字段。
- 费用快照不关联钱包、API 密钥或平台额度，不会产生扣费账本。
- 服务端未返回完整 usage 或价格缺失时，费用保持未知并写明原因，不生成零价快照。

## 网络边界

观测只解密 `chatgpt.com` 和 `api.openai.com` 的 443 连接。登录、刷新和其他主机使用原始隧道转发。上游出口复用 CodexManager 当前配置的代理；没有配置时直连。
